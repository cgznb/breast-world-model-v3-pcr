# 实验计划与结果解释

本包没有真实效果表，下面是需要执行的研究协议，不是实验结论。

## 主要假设

显式生成的未来若具有影像约束的状态，可能在有限纵向数据下帮助早期 pCR 预测。但生成结果不带来新的患者观测信息；应与使用相同纵向训练监督的直接判别模型比较，而不只比一个较弱单扫描分类器。

双流 coupling 是架构选择，是否有价值由不交互、后编码以及仅语义生成等匹配对照决定。Marginal BCE 应与 per-trajectory BCE 比较 NLL/Brier/多样性/校准，不应仅看 AUROC。需分别观察真实影像、生成影像和冻结外部分类器对同一未来的判断一致性。

## 至少保留的对照

临床先验；当前可见 MRI 的原 Pillar/TDN；相同纵向训练信息下不显式生成的强判别模型；原生成 MRI→Pillar→TDN；生成 latent→固定编码器→新 pCR；独立双流；完整双向耦合。真实全序列模型标注信息优势，不与 T0 模型当作同等输入比较。

`configs/ablations/` 是其中的内部消融，不冒充完成全部外部基线。所有 YAML 为生产 MONAI 模式，修改后端/时间模式时必须在新的 run 上一致进行；不同配置不能混用 checkpoint。

## 划分与报告

在患者级划分上同时约束生成器、编码器、教师适配、数值统计、临床先验和分类器。若使用曾接触历史 102 人开发队列的 V2 权重，不可把那批患者重新称为独立测试，仅更换随机种子不能消除暴露。外部基础模型的患者接触情况也需要披露。

每个起点分别报告 AUROC、AUPRC、Brier、NLL、校准、患者级置信区间，并配对比较模型。混合 landmark 的 aggregate 仅作摘要。当前 `by_observed_prefix` 按观察数量分组，正式论文应另外报告明确的 T0、T0–T1、T0–T2 协议，尤其当缺失扫描使数量与阶段不同。

生成评估需使用独立测量或预训练且未被联合优化的模型，检查局部肿瘤形态、相位关系、背景、分布覆盖和跨时间一致性。在非严格注册区域直接逐像素误差可能误导；应报告注册策略与质量控制。不要只选几张视觉好看的预测图。

## 采样稳定性

至少比较 K=1/2/4/8/16、不同种子和相同合法预测输入。K=1 可以做推理对照，但 Energy Score 训练需要 K>=2。每条轨迹分别读出后取概率均值，不能先平均图像。展示预测边际概率随 K 稳定性；K 增大不保证 AUROC 单调增加。

同样对 ODE 步数做真实影像质量与 pCR 稳定性对照。20步模型直接2步评估不等价于少步模型蒸馏。当前交付的2步 smoke 只验证工程。

## 失效诊断

如果生成质量下降而训练 pCR 上升，先降低 joint_lr/marginal_pcr、固定图像骨干、增加独立冻结评估，不要直接宣布模型学到了更重要的隐含医学特征。如果 dual state 与 image re-encoding 概率严重冲突，检查 grounding、教师状态尺度、VQ codebook匹配和分类器投机。

如果模型只依赖临床先验，检查独立临床基线、observed/future残差幅度与梯度，不以增加层数代替实验。若新大模型过拟合，应缩小语义/时序维度、用预训练编码器并规范验证，不能假定参数更多更“CVPR”。本次原生完整尺寸实例总参数约98.5M，其中包含固定教师；这一数字是资源信息，不是质量指标。

缺失随访本身可能携带预后相关选择机制。本版 mask 处理避免把缺失当阴性，但没有校正非随机缺失/随访选择偏倚，需要队列层面的敏感性分析。
