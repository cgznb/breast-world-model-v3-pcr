## 目标、数据和选模

主要部署场景固定为：只有 T0 MRI 与当时已知临床信息时，预测最终 pCR。
主指标固定为 102 名验证患者的 T0 full-future marginal NLL，越低越好。
AUROC、AP、Brier 和配对 bootstrap 是补充描述；不在看结果后更换主指标。
训练患者仍为 764 人，验证 102 人；没有独立测试集。这是开发验证，不是外部临床验证。

| 阶段 | 训练与选模规则 |
|---|---|
| A 表征 | 较低学习率 3e-5；pCR 辅助权重 0.10；保留重建/JEPA/状态重建。选模为固定验证重建+JEPA+0.10×T0 observed NLL；随机初始化不参与最佳选择。 |
| B 生成 | 保留配对 FM、语义 grounding/energy，新增自由生成 latent 均值 MSE 0.10、latent energy 0.05。选模改为 T0 完整自由生成的各随访阶段「生成均值 MSE / T0 持久性 MSE」平均。须完成后半程且实际执行三跳更新后才可入选。 |
| C 读出 | 学习率 1e-5，只更新 pCR 最后一个 Transformer block 和输出层；权重衰减 0.05。T0 自由未来、真实前缀和真实观测更新分支同时训练。step 0 入口可入选，只有 NLL 至少改善 0.001 才替换。 |
| D 联合 | 继承 C 的 best，包含 C step 0；非图像模块 1e-5，图像中间层/decoder 3e-6；pCR 更新范围仍为末块和输出层。按主 NLL 选择，且自由生成相对误差不能超过 D 入口的 1.10 倍；D 入口同样可保留。 |

B 的 marginal pCR 权重仍为 0；真实新 MRI 观测更新分支仍含 posterior pCR 监督，其梯度可通过冻结读出头进入状态和生成器。
不能把它描述成“B 完全没有 pCR 监督”。

网络宽度、层数和约 1.09 亿参数规模不增加。
pCR 输出改为训练集拟合的临床 prior 加有界残差：`prior + 2*tanh(residual/2)`；
输出层零初始化，初始预测等于临床 baseline。残差平方惩罚 0.01，readout dropout 0.20。

## 同患者对照和自由生成影像检查

所有验证用同一预定随机种子 20261001，K=4、Heun 每间隔 20 步。
每次正式验证使用全部 102 名 T0 患者，不因缺失后续随访而剔除；
T1/T2/T3 的真实历史比较另固定在完整且可及时获得 T0–T3 的 84 名患者中。
预测先完成，再加载未来真值评分；缺失真值仅使相应指标/损失缺项，不填补为真实观测。

同一患者、同一随机未来轨迹比较：临床 prior、真实 MRI 历史、生成联合语义未来、
同一生成 latent 经冻结 teacher 重新编码的未来。重新编码对照只替换 pCR 的未来 disease tokens，
保留相同当前真实 memory 和生成轨迹，不混入另一套生成动力学的差异。

影像指标覆盖每个未来阶段的单样本 MAE、生成均值 MAE/MSE、energy、样本离散度，
以及相同患者/相同未来可用性下的 T0 持久性基线。

预先按匿名患者 ID 排序选取前 8 名完整验证患者，打包 32 次 MRI 和固定 codec，
总计约 189 MiB。选择不使用 pCR 标签或生成质量。对这些患者额外完成：

- 解码每条生成样本，再求影像均值；与实际 MRI 和真实 latent 的解码 MRI 分别比较。
- 检查全体素、采集支持区域、固定 T0 定位 ROI 和有效的随访伪病灶 ROI。
- 使用相同强度坐标和显示范围，报告 codec 重建参考误差，不做逐图 min-max 归一化。
- 增加真正的 `生成 latent→解码 MRI→codec 连续编码→teacher` 读出探针，并与同 8 人的临床、真实 T0、联合未来和 latent 重编码比较。

ROI 来自模型自动定位/伪掩膜，不是专家病灶分割。空掩膜、裁剪不完整等情况明确排除该区域评分；
不能据此声称精确的肿瘤体积、边界或病理响应。8 人影像样例是开发集诊断子集。

B/C/D 结束后自动评估所选 best，而不是最后一次更新权重；保存完整比较、CSV 和解码图像。

## 预设实验与资源

主实验种子：20261011、20261012、20261013。均执行 A→B→C→D。
每阶段最大 optimizer steps：A 200，B 3000，C 150，D 400；
验证间隔分别 10/150/10/50，连续 4 次可入选验证未改善时早停。
较大 batch 后同步缩短步数，避免直接沿用旧步数导致训练样本抽取量成倍增加。

第一个种子另跑预先指定的单因素对照：A 学习率 1e-4；
C 仅输出层、C 全读出头、C 学习率 1e-4、C 残差惩罚为 0。
C 对照共享完全相同的 B best；其余设置保持主实验值。
这些诊断不自动替换预定主模型，也不据验证集调参结果宣称泛化提升。

| 阶段 | 实际物理 batch | 调度 |
|---|---:|---|
| A | 160 | 最多两个种子同时运行 |
| B | 32 | 独占训练资源 |
| C | 192 | 独占训练资源 |
| D | 32 | 独占训练资源 |

显卡为远端 GPU 0，RTX 5090，32607 MiB。只用真实计算增加显存占用。
阶段锁同时覆盖训练和评估；退出阶段前释放 CUDA 缓存，再允许下一种子进入。
验证 batch=32；训练 K=2，每条生成路径不截断反向传播。
批内仍按完整已观测前缀、未来真值可用性和标签可用性分组，允许有放回采样。
固定 T0 任务按患者等权选择组和组内患者，避免逆随访次数权重过度采样缺随访者。
batch 数字是物理任务数，不是新增独立患者数；稀少随访结构可能在批内重复抽到同一患者。

## 审计和恢复

主配置 `configs/ispy2_multistage_native_v3.yaml`，独立 v3 CLI/模型/损失/评估/训练器。
旧 v1/v2 配置序列化和摘要保持兼容。
每次运行记录配置、数据摘要、训练集统计、源文件摘要、固定患者列表和选模协议。
停止信号在完成 optimizer 步及该步必要验证后保存，保留优化器、采样器和 RNG 状态。
队列保存不可覆盖的启动收据、计划和进度；只在实际完成所需阶段/对照后标记完成。

工程检查中的未训练模型分数、合成数据分数和真实训练后结果严格区分。
完成新训练前，不宣称 v3 已优于 v2 或临床 baseline。
